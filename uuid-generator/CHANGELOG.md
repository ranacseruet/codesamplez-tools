# Changelog

All notable changes to this tool are documented in this file.

## [1.0.2] - 2026-11-27

### UUID Generator

- The generator is a full-width toolbar and a two-column workbench. Version 4 and version 7 are a segmented control. The page opens with one UUID, and each generated or validated UUID can be copied on its own. Generation and validation still run in the browser.

## [1.0.1] - 2026-11-26

### UUID Generator

- Shared page generator now includes the Unix Timestamp Converter. This tool's behavior is unchanged.

## [1.0.0] - 2026-11-26

### UUID Generator

- Generate version 4 and version 7 UUIDs, one or up to 100 at a time, with uppercase and no-hyphen formatting, copy, and download. Validate a pasted UUID and show its version, variant, and the version 7 timestamp. Generation and validation run in the browser. A tool_used event records the action, trigger, and outcome only. The UUID text is not sent.
