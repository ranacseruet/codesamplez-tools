# Support

## Where To Ask For Help

Use GitHub as the primary support channel for this repository.

- Bug reports: open a GitHub issue using the bug report template
- Feature requests: open a GitHub issue using the feature request template
- Usage questions or contributor workflow questions: review the documentation below first, then open a GitHub issue if the answer is still not clear

## Start With These Docs

- [README](./README.md)
- [Contributing Guidelines](./CONTRIBUTING.md)
- [UI Styling Conventions](./docs/ui-styling-conventions.md)

## Before Opening An Issue

Please include:

- The tool or shared surface involved
- What you expected to happen
- What actually happened
- Reproduction steps
- Browser and OS details for runtime bugs
- Validation evidence if the issue is about the build, tests, or contributor workflow

## Security Reports

Do not use GitHub issues for vulnerabilities or suspected security problems.
Follow the private reporting instructions in [SECURITY.md](./SECURITY.md).
